# Быстрый старт (3 минуты, без жаргона)

> Технический бэкграунд не нужен. Просто повторяйте за мной — 3 минуты до вашего первого «возражения» от ИИ.

## Единственное, что нужно запомнить

**После установки вам нужно запомнить всего одну команду: `/poe`**

Она сама разберётся, что вы пытаетесь сделать, и направит вас к нужному инструменту.
**Ни одно из 32 названий навыков учить не нужно.**

---

## Шаг 1 — Установка (≈30 секунд)

В терминале (в Windows: используйте Git Bash или WSL):

```bash
curl -fsSL https://raw.githubusercontent.com/wastefulthink/poeskill/main/install.sh | bash
```

Либо, если вы уже скачали папку проекта, выполните команду внутри неё:

```bash
bash install.sh
```

Установщик сам обнаруживает ваши ИИ-инструменты (Claude Code, Codex, Cline,
WorkBuddy, …), запрашивает подтверждение и устанавливает навыки. Вы увидите:

```
[poeskill] done. Run /poe in your Agent to get started.
```

> **Нет bash?** См. [Советы для Windows](#windows-tips).

## Шаг 2 — Скажите первую фразу (30 секунд)

Откройте ваш ИИ-инструмент и просто напишите — обычным языком, без формата:

```
/poe I have an idea: a coffee shop AI queue-ordering mini-app. Should I do it?
```

Всё. Дальше он разберётся сам.

## Шаг 3 — Почувствуйте возражение (2 минуты)

Обычный ИИ скажет: «отличная идея, вот как это построить». ИИ с poeskill
сначала поспорит с вами:

- Он оспорит вашу посылку: «**Очередь — действительно их самая
  болезненная проблема? Вы это проверяли?**»
- Он попросит доказательств: «Владелец реально будет за это платить? Есть
  подтверждение?»
- Он даст фальсифицируемый вывод: «**Не делайте — если только** не случится X»
  вместо «зависит от вашего исполнения».

**В этом весь смысл: он спорит первым, чтобы вы принимали лучшие решения.**

## Как понять, что установка прошла успешно?

| Способ | Как |
|---|---|
| Просто попробуйте | Введите `/poe` — если появится онбординг/маршрутизация, значит, установлено |
| Проверьте папку | В каталоге навыков есть 32 папки `poe-*` (например, `~/.claude/skills/`) |
| Проверьте вывод установки | `skills installed → <dir> (32 skills)` означает успех |

## Частые ситуации на простом языке

Эта таблица вам не обязательна — `/poe` маршрутизирует автоматически. Она
просто даёт мысленную карту:

| Что вам нужно | Просто скажите | Что происходит под капотом |
|---|---|---|
| Решить, стоит ли заниматься идеей | «помоги проанализировать, делать ли это» | `/poe-diagnosis` |
| Проверить факт или статью | «помоги проверить это утверждение» | `/poe-verify` |
| Не можете сформулировать, чего хотите | «помоги прояснить эту цель» | `/poe-goal` |
| Знаете, что делать, но не можете начать | «почему я вечно откладываю» | `/poe-action` |
| Модное словечко не значит ничего конкретного | «разбери это слово для меня» | `/poe-deconstruct` |
| Не получается хорошее начало | «помоги улучшить этот хук» | `/poe-hook` |
| Решение, о котором можно пожалеть позже | «помоги отслеживать это решение в долгую» | `/poe-decision` |

## Советы для Windows

1. **Используйте Git Bash или WSL** для запуска установщика — это bash-скрипт,
   и в обоих случаях bash уже есть.
2. **Вообще не хотите bash?** Не проблема: попросите кого-нибудь (или ваш
   ИИ-инструмент) выполнить установку за вас. После этого пользоваться им —
   просто вводить `/poe` — терминал больше не нужен.
3. **Куда всё установилось?** Установщик печатает `skills installed → <путь>`.
   Запомните этот путь.
4. **Установщик завис или ругается ошибкой?** Вставьте текст ошибки в `/poe`
   («у меня проблема с установкой») или откройте issue.

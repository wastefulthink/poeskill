**あなたのAIは、あなたに同意ばかりしていませんか？**

「このアイデア、いいと思う？」と聞けば「大きな可能性がありますね」と返ってくる。「やるべきかな？」と聞けば「実行次第でしょう」。

AIは決して「いいえ」と言いません。「本当に検証しましたか？」とも聞いてくれません。

poeskillはまさにそこを解決します。32個のスキルによって、どんなAIツールでも反論してくれるパートナーに変わります——まず前提を疑い、データを要求し、実際に反証できる結論を返してくれます。「なんとなく正しそう」ではなく、「正しいか間違っているか、こうやって確かめられる」と。

---

## なぜ作ったのか

私は長い間AIツールを使ってきて、ある傾向に気づきました。**賢くなるほど、同意するスピードが速くなる**ということです。

穴だらけの事業計画を渡せば、穴を埋めて返してくれます。曖昧な願望を渡せば、ステップに分解してくれます。しかし「待って、そもそも前提は正しいの？」と立ち止まる者は誰もいません。

良い意思決定は「実行を手伝って」からは生まれません。「問いを立てる手伝いをして」から生まれます。そこで私は25人の思想家たち——ヒュームからハイエク、ファインマンからカーネマンまで——の思考法を、出典付きの305個の知識ユニットへと蒸留し、コマンド一発でインストールできる32個のスキルに詰め込みました。

すべてのスキルはたった一つの設計原則に従っています。**助ける前に、まず議論すること。**

## 30秒でインストール

```bash
curl -fsSL https://raw.githubusercontent.com/wastefulthink/poeskill/main/install.sh | bash
```

またはローカルクローンから：

```bash
git clone https://github.com/wastefulthink/poeskill.git
cd poeskill
bash install.sh            # auto-detects your AI tool
bash install.sh --all      # install into every detected tool
bash install.sh --target ~/.claude/skills
```

Claude Code、Codex、Cline、WorkBuddy、Kiro、Qwen Codeなど、フォルダからスキルを読み込むエージェントであれば何でも動作します。

インストール後、**覚える必要があるのはコマンド1つだけ：`/poe`** です。32個のスキル名を覚える必要はありません。自動でルーティングされます。

## 最初の3分間

1. AIツールを開いて、普通の言葉でこう入力します：

   ```
   /poe I have an idea: a coffee shop AI queue app. Should I do it?
   ```

2. 普通のAIなら「いいアイデアですね。作り方はこうです」と言うでしょう。poeskillを入れたAIは、まず反論します：
   - 「行列は本当に彼らの最大のペインポイントですか？検証しましたか？」
   - 「店のオーナーは本当にこれにお金を払いますか？証拠はありますか？」
   - そして「実行次第」ではなく、「**Xが起きない限りやめるべき**」という結論を返します。

3. **まず反論してくれるから、より良い意思決定ができる。** それがすべてです。

はじめての方は、[3分間クイックスタート](QUICKSTART.en.md)を読んでみてください（専門用語ゼロ）。

## 何ができるか

**ビジネス課題の診断**
- `/poe-diagnosis` — ビジネスモデル診断（問診＋健康診断の2モード）
- `/poe-decision` — 長期案件の意思決定を、レビュー可能なローカルアーカイブに
- `/poe-standard-answer` — あなたのジレンマと同型の歴史的メカニズムを探す
- `/poe-benchmark` — ベンチマーク（对标）の選定と、スクリーニングによるノイズ除去

**コンテンツ制作のフルパイプライン**
- `/poe-good-question` — 曖昧な質問を推論可能な仕様書に書き直す
- `/poe-content` — 选题からコピーまで、コンテンツの総合診断
- `/poe-hook` — ショート動画の冒頭最適化
- `/poe-script-flow` — 台本の連続性チェックと離脱ポイント検出
- `/poe-resonate` / `/poe-spread` — 共鳴検出と伝播心理学
- `/poe-ai-check` — AI的な文体の痕跡検出
- `/poe-content-risk-check` — 公開前のリスクチェックとプラットフォーム審査対応
- `/poe-xhs-title` — 小紅書（RED）タイトルの型
- `/poe-wechat-html` — MarkdownからWeChat公式アカウント用HTMLへ

**思考・認知ツール**
- `/poe-deconstruct` — 言語分析の観点から曖昧な概念を解体
- `/poe-action` — 「やるべきことは分かっているのに動けない」の診断
- `/poe-slowisfast` — 焦りと必要な摩擦を見極め、複利的に積み上がる道を設計
- `/poe-goal` — 曖昧な願望を検証可能な目標に変換

**システムツール（poeskill自体の保守）**
- `/poe` — メインエントリ兼動的ルーター
- `/poe-chatroom` / `/poe-chatroom-market` — 多ロール対論（市場秩序学派の視点を含む）
- `/poe-save` / `/poe-restore` / `/poe-report` — 診断状態の保存・復元・レポート化
- `/poe-knowledge` / `/poe-content-system` — ローカル知識ベースとコンテンツ資産のエンジニアリング
- `/poe-learning` — インタラクティブ学習
- `/poe-verify` — あらゆる結論への反証チェック（証拠の遡行／反例検索／情報源の強度評価／利益相反チェック）
- `/poe-update` — 本リポジトリからの自己更新
- `/poe-bridge` / `/poe-agent-migration` — 他エージェントへのブリッジとワークスペース移行
- `/poe-skill-cleaner` — スキルに隠れた商業的意図の監査

## 効果は測定可能

同じビジネス上の意思決定を、同じモデルで2回実行——素の状態とpoeskill入りで。ケース01では、素のモデルが**6/25**、poeskillは**25/25**。同じモデル、同じ質問。唯一の違いは、AIに「反論しなさい」と伝えたかどうかです。

```bash
python benchmark/run_benchmark.py --prompt both   # needs an API key
```

ケース、プロンプト、実行スクリプト、採点ルブリックは [`benchmark/`](benchmark/) を参照してください。**この差こそがプロダクトです。**

## なぜ「poe」という名前か

3つの意味が重なっています：

1. **エドガー・アラン・ポーへのオマージュ** — 探偵小説の祖。彼の探偵は表層の物語を決して信じず、小さな手がかりから真実を再構築します。それはまさにこのツールボックスの気質です。`/poe-diagnosis`は症状から根本原因をたどり、`/poe-verify`は反証で結論をストレステストし、`/poe-deconstruct`は乱用されたバズワードを解体します。
2. **Problem-Oriented Engine（問題指向エンジン）** — すべてのツールは答えではなく、問題から出発します。
3. **独立した名前** — 短く、覚えやすく、主要な言語で否定的な含意がない。

## スターをつけるべき理由

- **反論してくれるから。** 存在意義そのものが「意見が違う」ことです。すべての診断系スキルは、結論に反証可能な条件と情報源の強度評価を必ず添付します。
- **すべてが検証可能。** 305ユニット、それぞれに出典付き。根拠のない感覚も「私を信じて」もありません。
- **ローカルで動く。** テレメトリなし、SaaSなし、アカウントなし。あなたの質問がマシンの外に出ることはありません。
- **MIT＋完全オリジナル。** ゼロから書かれています。フォークしても、組み込んでも、土台にしても構いません。

---

## 批判的に使うこと（重要）

poeskillは思考ツールであり、回答機ではありません：

1. 結論を出すすべてのスキルは、情報源の強度評価（A/B/C/D）を**必ず**添付します。C未満は単なるアイデアです
2. 定性的な帰属には、反証可能な条件を伴わせます
3. 不確かなときは、`/poe-verify`で反証チェックを実行します
4. 重要な意思決定（投資、キャリア、健康）ではクロスバリデーションを。単一フレームワークを信じてはいけません
5. `/poe-action`などの心理系ツールは自己理解の補助であり、心理療法ではありません

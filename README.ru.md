**Ваш ИИ постоянно с вами соглашается.**

Вы спрашиваете: «стоит ли заниматься этой идеей?» — он отвечает: «большой потенциал». Вы спрашиваете: «мне это делать?» — он отвечает: «зависит от вашего исполнения».

Он никогда не говорит «нет». Он никогда не спросит: «а вы это проверяли?»

poeskill решает именно эту проблему. 32 навыка (skills), которые превращают любой ИИ-инструмент в партнёра, способного возражать: сначала он ставит под сомнение вашу посылку, требует данные — и только потом выдаёт вывод, который можно реально проверить на ложность. Не «звучит логично», а «верно или неверно — вот как это проверить».

---

## Зачем мы это сделали

Я долго пользовался ИИ-инструментами и заметил закономерность: **чем умнее становится модель, тем быстрее она с вами соглашается.**

Вы даёте ей бизнес-план, полный дыр, — она их аккуратно закрашивает. Вы формулируете расплывчатое желание — она разбивает его на шаги, но никто не останавливается, чтобы спросить: «погодите, а посылка вообще верна?»

Хорошие решения рождаются не из «помоги мне исполнить», а из «помоги мне усомниться». Поэтому я взял мыслительные методы 25 мыслителей — от Юма до Хайека, от Фейнмана до Канемана — дистиллировал их в 305 снабжённых ссылками знаний (knowledge units) и упаковал в 32 навыка, каждый из которых устанавливается одной командой.

Каждый навык следует одному принципу проектирования: **он обязан поспорить с вами, прежде чем помочь вам.**

## Установка за 30 секунд

```bash
curl -fsSL https://raw.githubusercontent.com/wastefulthink/poeskill/main/install.sh | bash
```

Или из локального клона:

```bash
git clone https://github.com/wastefulthink/poeskill.git
cd poeskill
bash install.sh            # auto-detects your AI tool
bash install.sh --all      # install into every detected tool
bash install.sh --target ~/.claude/skills
```

Работает с Claude Code, Codex, Cline, WorkBuddy, Kiro, Qwen Code — с любым агентом, который читает навыки из папки.

После установки **вам нужно запомнить всего одну команду: `/poe`.** Не учите ни одно из 32 названий навыков — маршрутизация происходит автоматически.

## Ваши первые 3 минуты

1. Откройте ваш ИИ-инструмент и напишите обычным языком:

   ```
   /poe I have an idea: a coffee shop AI queue app. Should I do it?
   ```

2. Обычный ИИ скажет: «отличная идея, вот как это построить». ИИ с poeskill сначала поспорит:
   - «Очередь — действительно их самая болезненная проблема? Вы это проверяли?»
   - «Владелец реально будет за это платить? Есть подтверждение?»
   - А затем: «**Не делайте — если только** не случится X» вместо «зависит от вашего исполнения».

3. **Он спорит с вами первым — чтобы вы принимали лучшие решения.** В этом весь смысл.

Вы здесь впервые? Прочитайте [быстрый старт за 3 минуты](QUICKSTART.en.md) (ноль жаргона).

## Что он умеет

**Диагностика бизнес-проблем**
- `/poe-diagnosis` — диагностика бизнес-модели, режимы консультации и checkup
- `/poe-decision` — превращение долгосрочных решений в ревью-able локальные архивы
- `/poe-standard-answer` — поиск исторических механизмов, изоморфных вашей дилемме
- `/poe-benchmark` — поиск бенчмарков, отсев шума методикой пяти фильтров

**Полный контент-конвейер**
- `/poe-good-question` — переписывание расплывчатых вопросов в спецификации, готовые к рассуждению
- `/poe-content` — полная диагностика контента: от темы до текста
- `/poe-hook` — оптимизация начал коротких видео
- `/poe-script-flow` — проверка связности сценария и точек отвалов
- `/poe-resonate` / `/poe-spread` — детекция резонанса и психология коммуникации
- `/poe-ai-check` — обнаружение следов ИИ-писанины
- `/poe-content-risk-check` — проверка рисков и модерации платформ перед публикацией
- `/poe-xhs-title` — формулы заголовков для Xiaohongshu (RED)
- `/poe-wechat-html` — Markdown в HTML для официальных аккаунтов WeChat

**Инструменты мышления / когнитивные**
- `/poe-deconstruct` — разбор расплывчатых понятий методами лингвистического анализа
- `/poe-action` — диагностика «понимаю, что делать, но не двигаюсь с места»
- `/poe-slowisfast` — различение спешки и необходимого трения, проектирование путей со сложным процентом
- `/poe-goal` — превращение расплывчатых желаний в проверяемые цели

**Системные инструменты (обслуживание самого poeskill)**
- `/poe` — главный вход и динамический маршрутизатор
- `/poe-chatroom` / `/poe-chatroom-market` — дискуссии нескольких ролей (включая взгляд школы рыночного порядка)
- `/poe-save` / `/poe-restore` / `/poe-report` — архивирование состояния диагностики и отчёты
- `/poe-knowledge` / `/poe-content-system` — локальная база знаний и инженерия контент-активов
- `/poe-learning` — интерактивное обучение
- `/poe-verify` — контрпроверка любого вывода (трассировка источников / контрпримеры / градация надёжности источников / проверка конфликта интересов)
- `/poe-update` — самообновление из этого репозитория
- `/poe-bridge` / `/poe-agent-migration` — мост к другим агентам и миграция рабочих пространств
- `/poe-skill-cleaner` — аудит навыков на скрытые коммерческие намерения

## Почему название «poe»

Три слоя:

1. **Дань уважения Эдгару Аллану По** — родоначальнику детективной прозы. Его сыщики никогда не верят поверхностным нарративам; они восстанавливают истину по мелким уликам. Это и есть темперамент данного тулбокса: `/poe-diagnosis` прослеживает симптомы до корневых причин, `/poe-verify` стресс-тестирует выводы контрдоказательствами, `/poe-deconstruct` разбирает по косточкам заезженные модные словечки.
2. **Problem-Oriented Engine** — каждый инструмент стартует от проблемы, а не от готового ответа.
3. **Независимое имя** — короткое, запоминающееся, без негативных коннотаций ни в одном из основных языков.

## Почему стоит поставить звёздочку этому репозиторию

- **Он с вами спорит.** Весь смысл — в несогласии: каждый диагностический навык обязан приложить к своему выводу фальсифицируемое условие и градацию надёжности источника.
- **Всё проверяемо.** 305 единиц, у каждой — ссылка на первоисточник. Никаких вибраций, никаких «поверь мне».
- **Работает локально.** Никакой телеметрии, никакого SaaS, никаких аккаунтов. Ваши вопросы не покидают вашу машину.
- **MIT + полностью оригинальный код.** Написано с нуля. Форкайте, вендорьте, стройте на его основе.

## Критичное использование (важно)

poeskill — инструмент мышления, а не машина ответов:

1. Каждый навык, выдающий выводы, **обязан** прикладывать градацию надёжности источника (A/B/C/D); ниже C — это лишь идея
2. Качественные атрибуции должны сопровождаться фальсифицируемыми условиями
3. Если сомневаетесь — запускайте `/poe-verify` для контрпроверки
4. Для ставок с высокими рисками (инвестиции, карьера, здоровье) перекрёстно валидируйте — никогда не доверяйте единственному фреймворку
5. `/poe-action` и другие психологические инструменты — помощники в самопознании, а не психотерапия

## Обновление

- Главный вход проверяет `UPDATE.json` не чаще одного раза в 24 часа
- `/poe-update` синхронизируется с этим репозиторием, сохраняя ваш архив `~/.poe/`
- Перед обновлением сделайте `git pull`, чтобы просмотреть изменения
